# Difficulty ladder — test accuracy across the grid

Generated by `examples/lra_difficulty_ladder.py` from `difficulty_ladder/config.yaml`.

Test accuracy is from the epoch with the best validation accuracy, one seed, `lr` 1e-3.

`± res` is the smallest difference between two models in that row that the test split can resolve: $2\sqrt{2}\,\sqrt{p(1-p)/n}$ at the row's best accuracy, floored at $3/n$ so a saturated row is not reported as exact. It counts evaluation sampling noise only — with one seed there is no measurement of seed-to-seed variation at all.

**Cells are different tasks.** `step_size` sets both `seq_len` and `input_size`, so a comparison across rows is not controlled; only the comparison across columns *within* a row is.
